Which workflow architecture should the document recommend?

The deliverable will explain a lean OpenSpec × Linear × GitHub lifecycle, repo-local policy, delegated PR ownership, and safe cleanup.

A

Native-first composition recommended

One root coordinator routes to four stage skills, existing OpenSpec/review skills, native AgentHub and worktree helpers. Keep repo orchestration on the default branch; agents own isolated work branches through PR cleanup.

B

AgentHub-led policy

Put all lifecycle behavior in a global Omp AgentHub rule and let the hub control workers. Strong visibility, but couples governance to one client/runtime and increases always-loaded policy.

C

Automation-led controller

Make schedules/hooks drive intake, dispatch, checks, and cleanup. Lower manual overhead, but expands into runtime infrastructure, duplicate-claim/retry problems, and irreversible permission boundaries.
